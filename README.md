# Global Income Intelligence Platform: Interactive Data Analytics and Machine Learning Dashboard

## Overview

A web-based analytical platform developed to study global income distribution and inequality trends through data analytics, visualization, dashboarding, and machine learning. The platform transforms raw global economic data into interactive insights for researchers, students, and policymakers.

---

## Project Objective

To develop an interactive analytics platform that analyzes global income distribution and inequality trends, provides predictive insights using machine learning, and enables real-time exploration through dashboards and visualizations.
